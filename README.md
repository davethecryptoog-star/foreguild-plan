# Sell the content, not the contest

An operating plan for **Foreguild**, the futarchy-governed AI job board, written for Seer's FAO Operating Plan Contest (Poidh Base #1531).

By **Oliver Dave** ([@DaveTheCryptoOG](https://x.com/DaveTheCryptoOG)). Independent, non-internal entry. Drafted with AI assistance.

- **Read the plan:** https://davethecryptoog-star.github.io/foreguild-plan/
- **PDF:** [foreguild-operating-plan.pdf](foreguild-operating-plan.pdf)
- **Live demo market (Seer, Base):** https://app.seer.pm/markets/8453/0xBF1111a082B196328612DcC4D9eB973dABC5CbF8

## What is in this repository

| File | What it is |
|---|---|
| `index.html` | The full plan, self-contained, with an interactive revenue calculator |
| `foreguild-operating-plan.pdf` | The same plan as a PDF |
| `model.py` | The revenue model behind every table. `python3 model.py` prints the scenarios; `python3 model.py --json` prints the full monthly ledger |
| `census.csv` | The 27 content contests counted on X on 8 November 2026, one link per project (Appendix A) |
| `demo/` | The three graphics posted for the live demo (Appendix B) |

Every figure in the plan is labelled Fact or Assumption.
